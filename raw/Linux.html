    Linux开发环境基础知识¶

    先说结论

    做实验时，你不需要一下子学会所有 Linux 命令。先掌握下面这些就够用了： 登录环境、切换目录、查看文件、运行命令、看报错、会复制删除、会用管道和重定向 。

    推荐学习方式

    一边看，一边在终端里自己敲一遍。Linux 不是靠背会的，而是靠用会的。

    1. 如何进入 Linux¶

    常见方式有 3 种：

    • 远程实验平台 ：推荐用 VSCode 连接，具体见远程实验平台使用指南
    • 实验室/个人虚拟机 ：启动虚拟机后登录即可
    • WSL2 ：Windows 同学可直接打开 Ubuntu/WSL 终端

    如果你只是想尽快开始做实验， 优先推荐 VSCode + 终端 这种方式。

    2. 先理解 3 个最重要的概念¶

    2.1 当前目录¶

    终端里每条命令，都是在“当前目录”下执行的。

    pwd
    • pwd 的作用：显示你当前所在的位置
    • 如果命令运行结果不对，第一件事通常就是先执行一次 pwd

    2.2 路径¶

    Linux 用路径表示文件位置，常见两种：

    • 绝对路径 ：从根目录 / 开始写，例如 /home/学号/xv6-oslabs-hitsz
    • 相对路径 ：从当前目录开始写，例如 ./kernel、../user

    3 个特别常见的写法：

    • .：当前目录
    • ..：上一级目录
    • ~：家目录

    例子：

    cd ~
pwd
cd ..
pwd

    2.3 文件和目录是一棵树¶

    你可以把 Linux 文件系统理解成一棵树：

    • / 是根
    • 每个目录下面还可以继续有目录和文件
    • 你平时最常待的地方通常是自己的家目录 ~

    3. 最常用命令¶

    下面这些命令，建议先学会。

    3.1 目录与文件¶

    命令 作用 常见用法
    pwd 查看当前目录 pwd
    ls 查看目录内容 ls、ls -lah
    cd 切换目录 cd ~、cd ..、cd -
    mkdir 创建目录 mkdir lab1、mkdir -p a/b/c
    touch 创建空文件 touch a.txt
    cp 复制文件/目录 cp a b、cp -r dir1 dir2
    mv 移动/重命名 mv a.txt b.txt
    rm 删除文件/目录 rm a.txt、rm -r dir
    cat 直接查看文件内容 cat README.md
    less 分页查看文件 less README.md

    关于 rm

    请谨慎使用 rm。 在 Linux 中，rm 删除后通常 没有回收站 ，删错了往往很难恢复。拿不准时，先用 ls 确认目标文件，再执行删除命令。

    3.2 搜索与查看¶

    命令 作用 常见用法
    find 查找文件 find . -name "*.c"
    grep 查找文字 grep -n "fork" kernel/proc.c
    head 看文件开头几行 head README.md
    tail 看文件最后几行 tail -n 20 log.txt

    3.3 进程与系统状态¶

    命令 作用 常见用法
    top 查看系统进程 top
    ps aux 查看当前所有进程 ps aux
    kill 结束进程 kill pid、kill -9 pid
    df -h 查看磁盘空间 df -h
    free -h 查看内存使用 free -h

    4. 终端里最好先会的快捷键¶

    • Tab：自动补全命令或文件名
    • 连按两次 Tab：显示可补全项
    • ↑ / ↓：翻历史命令
    • Ctrl + C：中止当前命令
    • Ctrl + L：清屏
    • Ctrl + U：删除当前行光标前的内容

    如果某个程序“卡住了”，先试试 Ctrl + C。

    5. 实验里最常见的操作流程¶

    假设你已经进入实验目录：

    cd ~/xv6-oslabs-hitsz
ls
git status
make qemu

    建议养成这个习惯：

    1. 先 pwd 看自己在哪
    2. 再 ls 看当前目录里有什么
    3. 再执行真正的命令

    这样能避免很多“命令没错，但目录错了”的问题。

    6. 管道与重定向¶

    这一部分实验里会经常见到，但只要先会最常用的几种即可。

    6.1 管道 |¶

    管道的意思是： 把前一个命令的输出，交给后一个命令继续处理 。

    例子：

    ls | grep kernel
ps aux | grep qemu
cat README.md | grep xv6

    你可以简单理解成“把两条命令接起来用”。

    6.2 输出重定向 > 和 >>¶

    • >：覆盖写入文件
    • >>：追加写入文件

    例子：

    echo hello > a.txt
echo world >> a.txt
cat a.txt

    6.3 输入重定向 <¶

    把文件内容作为命令输入：

    wc -l < a.txt

    6.4 错误输出重定向 2>¶

    有些命令报错信息不会进普通输出，而是进入“错误输出”。

    make 2> err.log

    如果想把正常输出和报错都保存下来：

    make > build.log 2>&1

    7. 环境变量：先会最常用的两个¶

    环境变量可以理解成“系统记住的一些配置”。

    7.1 查看环境变量¶

    env
echo $HOME
echo $PATH

    最常用的两个：

    • HOME：你的家目录
    • PATH：系统去哪些目录里找命令

    7.2 临时修改环境变量¶

    export PATH=$PATH:/test
echo $PATH

    这类修改通常只对 当前终端 有效。

    7.3 永久生效怎么做¶

    如果指导书明确要求你配置环境变量，通常做法是把命令写进配置文件：

    • bash 用户常见是 ~/.bashrc
    • zsh 用户常见是 ~/.zshrc

    修改完成后执行：

    source ~/.bashrc

    如果你用的是 zsh，就改成：

    source ~/.zshrc

    环境变量不要乱改

    如果实验没有明确要求，就不要随意修改 PATH 等关键变量。改错后可能导致命令无法使用。

    8. 本课程高频命令补充¶

    前面的内容足够你“会用终端”。下面这些是 本课程实验里高频出现 的命令，建议也一起掌握。

    8.1 Git 最小集合¶

    虽然 Git 的完整用法在实验实用工具里有更详细的说明，但至少建议先会下面这些：

    命令 作用
    git clone 仓库地址 下载代码仓库
    git status 查看当前有没有改动
    git branch 查看本地分支
    git checkout 分支名 切换到指定分支
    git add 文件名 把改动加入暂存区
    git commit -m "说明" 保存一次版本
    git pull 拉取远程更新
    git push 把本地提交推到远程

    对本课程来说，最常见的场景就是：

    git status
git add 你改过的文件
git commit -m "完成 Lab1 的 sleep"

    8.2 编译、运行、测试¶

    XV6 实验里最常见的是这些命令：

    命令 作用
    make qemu 编译并启动 xv6
    make grade 运行实验测试
    make clean 清理旧编译结果和部分中间文件
    ./grade-lab-util sleep 运行某个分项测试
    ./grade-lab-syscall yield 运行指定测试脚本

    你可以把 make 理解成“按 Makefile 里写好的规则自动做事”。

    • make qemu：最常用，表示编译并运行
    • make grade：最常用，表示跑测试
    • make clean：当环境有点乱、旧文件影响结果时经常有用

    如何退出 xv6

    运行 make qemu 后，如果你想退出 xv6，一般按：Ctrl + a，再按 x。

    8.3 脚本、权限与退出码¶

    实验里经常会直接运行脚本，比如 test.sh、start.sh。

    命令 作用
    chmod +x test.sh 给脚本增加可执行权限
    ./test.sh 运行当前目录下的脚本
    bash test.sh 用 bash 解释器运行脚本
    echo $? 查看上一条命令是否成功

    说明：

    • ./test.sh 前面的 ./ 表示“运行当前目录里的这个文件”
    • 如果提示 Permission denied，常常是因为没有执行权限，需要先 chmod +x
    • 通常 echo $? 输出 0 表示上一条命令成功，非 0 表示失败

    8.4 远程连接与环境安装时常见的命令¶

    如果你使用远程实验平台或自行部署环境，下面这些命令也很常见：

    命令 作用
    ssh 用户名@IP -p 端口 连接远程 Linux 主机
    sudo apt-get update 更新软件包列表
    sudo apt-get install 包名 安装软件
    unzip 文件名.zip 解压 zip 文件
    source ~/.bashrc 让配置立即生效

    例如远程实验平台常见写法：

    ssh 你的学号@10.249.12.98 -p 6666

    8.5 Lab5 文件系统实验里常见的命令¶

    Lab5 不是 xv6，而是用户态文件系统实验，会频繁用到这些命令：

    命令 作用
    mkdir 建目录
    touch 建空文件
    ls 查看目录内容
    cat 查看文件内容
    fusermount -u ./tests/mnt 卸载 FUSE 文件系统

    如果 Lab5 测试后提示挂载点忙、文件系统没卸载干净，第一反应通常就是检查是否需要执行：

    fusermount -u ./tests/mnt

    9. 不会某个命令时怎么办¶

    先按这个顺序排查：

    1. pwd：确认自己在哪个目录
    2. ls：确认文件在不在
    3. 命令 --help：先看帮助
    4. man 命令：看更完整说明
    5. 看报错的 最后一行 ，通常最有用

    例如：

    ls --help
man grep

    10. 建议你自己练一遍¶

    如果下面这些命令你都能独立敲出来，就已经足够开始做实验了：

    cd ~
mkdir linux-test
cd linux-test
touch a.txt
mkdir dir1
cp a.txt dir1/
ls -lah
pwd
find . -name "*.txt"
echo hello > a.txt
cat a.txt
echo 'echo hello linux' > run.sh
chmod +x run.sh
./run.sh
git status

    如果你还能看懂并使用 git checkout、make qemu、make grade、./test.sh、fusermount -u 这些命令，就已经足够覆盖本课程实验的大部分 Linux 使用场景。
