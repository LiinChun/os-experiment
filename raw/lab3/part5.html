    AI 推理服务附加题¶

    本附加题独立于 Lab3 基础锁实验评分：基础实验运行 make grade（70 分），AI 附加题运行 make grade-ai（30 分）。先完成 kalloc 和 bcache 的基础实验，再选择参与 AI 附加题。先看下面的实验要求，再按需阅读背景和实现指导；不必先读完全部原理。

    实验要求¶

    项目 分值 需要完成什么 验证入口
    模型与 embedding 加载 6 从 xv6 文件读取两类共 74 个、每个 1024 字节的分片；正确返回内容，缓存命中不重复统计文件读取，并在结束时清理资源。 ./grade-ai "AI 模型" / aimodeltest
    KV 持久化与恢复 8 每请求完整写入和恢复 2048 字节；写后释放旧页，读入新页；按编号顺序处理，非法请求安全拒绝，多 worker 文件相互隔离。 ./grade-ai "AI KV 持久化" / aikvtest
    逐 worker、逐请求输出等价 6 运行 3 个 worker、每个 24 个请求；student 与 baseline 的输出及规定 I/O 一致。 ./grade-ai "AI 两条通路" / aiinfer compare -w 3 -r 24
    相对性能 6 保持输出等价，在相同环境下比较吞吐、自旋和 p95；记录原始数据并解释瓶颈。 make grade-ai；三轮测量仅用于分析
    KV cache-aware prefetch 4 在不跳过文件恢复的前提下，让下一条 KV 读取与当前请求计算重叠；保持输出与 I/O 等价、资源完整回收。无需保证在每台机器上加速。 ./grade-ai prefetch

    五项共 30 分，prefetch 是其中计 4 分的一项；各项得分以完成并通过相应检查为准，AI 附加题整体不影响基础实验的 70 分。模型和 KV 可分别完成单项检查；逐请求等价和性能要求先有可运行的 student 通路。make grade-ai 对性能项按一次评分运行的倍率给分；python3 tools/grade_ai.py --runs 3 另外计算三轮中位数，用于分析波动和保存证据，不替代评分命令，也不决定最终 6 分。

    可修改文件与提交物¶

    AI 实现只修改 user/ai_student.c、user/ai_student_model.c、user/ai_student_kv.c、user/ai_student_prefetch.c 中实际完成的部分。完成相应模块后设置 ai_student.c 内的实现标志。不要改 baseline、workload、公共接口、模型资产、测试、评分器或 Makefile 来绕过验证。

    基础实验与 AI 附加题在 grader 中有不同提交通道。AI 通道的 commit.patch 必须同时包含基础锁实验的修改（kernel/kalloc.c、kernel/bio.c、time.txt）和自己完成的 AI 文件；附上 AI 报告及性能证据，按附加题提交操作。当前学生初始代码标签为 lock-26-fall-v2，应用补丁时应以此标签对应的干净代码验证。

    建议的完成顺序¶

    1. 在 xv6 shell 运行 modelprep，确认 74 个教学分片生成成功；阅读数据背景与经典 baseline 链路。
    2. 完成模型加载，运行 aimodeltest 或在 Linux 终端运行 ./grade-ai "AI 模型"；通过后再启用对应实现标志。
    3. 完成KV 写入、释放与恢复。aikvtest 应显示 AIKVTEST: request order OK 和 AIKVTEST: verify OK requests=4 bytes=8192，表示写/读阶段各完成四条记录共 8192 字节，并通过非法编号拒绝检查；通过后再启用 KV 标志。
    4. 运行 aiinfer student -w 3 -r 24 和 aiinfer compare -w 3 -r 24，检查每个 worker 和请求的输出、checksum 与 I/O 等价。
    5. 在 Linux 终端运行 make grade-ai 获取正式附加题评分；再运行 python3 tools/grade_ai.py --runs 3 保存重复测量数据并解释吞吐、p95、自旋的变化。需要时查阅测试与故障定位。
    6. 完成prefetch 任务后，单独验证 aiinfer prefetch -w 3 -r 24、./grade-ai prefetch，并使用 python3 tools/grade_ai.py --runs 3 --bonus 观察开销。

    手动在 xv6 shell 运行 AI 测试前要先运行 modelprep；make grade-ai 在项目根目录清理、重建并执行完整评分。表中的 ./grade-ai "AI KV 持久化" 等带引号命令是评分脚本支持的单项过滤：参数按测试标题的子串匹配，引号用于将含空格的标题片段作为一个参数，并非另加的中文子命令。运行失败时应先定位单项接口，不要用性能数字代替正确性证明。三轮测量脚本目前有短过滤词误选测试的限制；如它在输出 JSON 前中止，按性能页的独立指标检查保存原始数据，不把脚本中止直接当作接口失败。
